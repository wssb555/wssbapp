文件概述

这是一个 Node.js 诊断脚本，通过 Chrome DevTools Protocol (CDP) 远程调试接口来检测和操控一个运行中的 Chrome 浏览器页面。目标网站是 hbgbzx.gov.cn（看起来是湖北省的一个干部在线学习/培训平台）。

主要功能模块

1. 基础工具函数

  • getPages() — 通过 http://127.0.0.1:9222/json 获取 Chrome 所有打开的标签页列表
  • cdpSend(ws, method, params) — 通过 WebSocket 发送 CDP 命令，带 30 秒超时
  • evaluate(ws, expr) — 在目标页面执行 JavaScript 表达式并返回结果
  • sleep(ms) — 简单的延时函数

2. 主流程 (main 函数)

脚本按顺序执行以下诊断步骤：

步骤说明
扩展检测检查 document.visibilityState 和 document.hidden 是否被重写（stealth.js 的特征），检查 navigator.webdriver 状态
登录状态检查检查 cookies、localStorage 中的 token、页面上是否有登录按钮或用户名元素
导航到课程页跳转到 #/study_center/my_course，查找未完成的课程（进度 < 100%）
点击课程自动点击第一个"开始学习"按钮，进入视频播放页
视频页检测检查是否有 <video> 元素、播放速率、暂停状态、章节数量等
再次检测 stealth在视频页再次验证 visibilityState 是否被覆盖
扩展 Service Worker 检查查找 Chrome 扩展的后台 service worker 目标

实际用途

这个脚本本质上是一个自动化在线学习/刷课的诊断工具，用来：

  1. 确认浏览器扩展（stealth.js）是否正常运行——该扩展会伪装页面可见性，让网站以为用户一直在前台观看视频
  2. 验证登录状态是否有效
  3. 自动找到未完成的课程并点击进入
  4. 确认视频页面的状态是否正常

简单来说，这是配合某个浏览器扩展使用的调试脚本，用于排查自动挂课过程中可能出现的问题。
